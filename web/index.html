Seven planes, one accountable pipeline

Three ways to ask

Every mode returns the same shape: an answer, its confidence, and its sources.

Fast

single pass

Straight lexical + vector retrieval, reranked once, answered immediately.

Auto

default

Balances latency and depth — escalates to graph traversal when it helps.

Research

agentic

A bounded multi-step loop that plans, retrieves, and re-checks its own claims.
