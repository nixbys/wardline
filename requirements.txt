# For Vercel's Python builder, which installs from this file rather than
# building the project the way docker/Dockerfile.api does (`pip install -e
# ".[dev]"`). "." tells pip to install this project itself (pulling in
# every dependency already declared in pyproject.toml's [project.dependencies]
# in the process) so `wardline` is importable the way api/main.py's own
# `from wardline...` absolute imports expect -- not just the third-party
# packages a hand-copied list would give you.
#
# requirements-lock.txt (hash-pinned, generated via scripts/regenerate_lockfile.sh)
# is what docker/Dockerfile.api installs from for reproducible container
# builds; deliberately not used here; see [tool.vercel] in pyproject.toml
# for why a Vercel deploy of this project needs more than this one file
# to actually work.
.
